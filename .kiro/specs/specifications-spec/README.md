# Especificaciones de Desarrollo

Este directorio contiene las guías de estándares y pautas para cada tecnología utilizada en el proyecto. Úsalas para darme instrucciones más precisas y obtener código que siga tus convenciones.

## Cómo usar estas especificaciones

1. **Antes de pedir código**: Referencia el spec de la tecnología que vas a usar
   - Ejemplo: "Crea un componente React siguiendo #[[file:spec/REACT.md]]"
   - Ejemplo: "Implementa esta función en Node siguiendo #[[file:spec/NODE.md]]"

2. **En tus instrucciones**: Simplemente menciona la tecnología
   - "Crea esto en Python siguiendo los estándares"
   - "Implementa esto en React"

## Tecnologías cubiertas

- **NODE.md** - Node.js, Express, TypeScript backend
- **REACT.md** - React, componentes, hooks, testing
- **PYTHON.md** - Python, FastAPI, Django
- **DATABASE.md** - Prisma, SQL, migraciones
- **TESTING.md** - Jest, testing patterns
- **GENERAL.md** - Estándares generales del proyecto

---

**Nota**: Cada spec incluye:

- Estructura de carpetas
- Convenciones de nombres
- Patrones de código
- Dependencias recomendadas
- Ejemplos de implementación
